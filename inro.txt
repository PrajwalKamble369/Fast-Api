FastAPI:
It is modern high performance web framework for building APIs with Python.

It is built on starlette and pydantic which are Python Liabraries.

api recive http request from client and perform some process on this request, and in return genrate respose in http in this starlette do this

pydantic is used to check if the data coming into your API is correct and in the right format.
